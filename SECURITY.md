# Security policy

Please report a suspected vulnerability through [GitHub private vulnerability reporting](https://github.com/0xTrey/fasting-tracker-webmcp/security/advisories/new). Do not include live credentials, tokens, cookies, private fasting data, or exploit details in a public issue.

This repository contains placeholder deployment identifiers and example secret names. It should never contain plaintext production credentials.

## Supported version

Security fixes target the current `main` branch.

## Public demo boundary

The hosted competition demo contains synthetic records. Its admin and remote MCP routes are disabled. A report that affects only intentionally synthetic content may still be useful, but it is not a disclosure of private fasting data.
